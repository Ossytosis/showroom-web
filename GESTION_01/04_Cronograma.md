**Esfuerzo total estimado:** 15 horas

| Dia | Actividad | Entregable |
|---|---|---|
| 1 | Preparacion y planificacion | Trello, estructura y Git |
| 2 | Diseno y estructura HTML | Estructura visual |
| 3 | Catalogo estatico | Tarjetas y navegacion |
| 4 | CSS responsive | Interfaz adaptable |

| 15 | Documentacion y cierre | README y demostracion |

## Reglas de planificacion

1. Cada sesion tiene una tarea principal.
2. Al iniciar, revisar la tarea pendiente en Trello.
3. Al terminar, registrar avances, dificultades y siguiente paso.
4. Guardar cambios funcionales en Git.
5. Si una tarea excede el tiempo previsto, actualizar el plan.
6. No marcar como terminado algo que no se haya probado.
7. Priorizar un MVP funcional antes de agregar caracteristicas secundarias.

## Riesgos

- Curva de aprendizaje de Node.js, Express y MySQL.
- Errores de configuracion del entorno.
- Tiempo insuficiente para funciones adicionales.
- Problemas de despliegue o configuracion externa.

## Criterio de cierre

Al finalizar el plazo, se documentara que funciones estan implementadas, cuales fueron probadas, cuales estan pendientes y que trabajo se recomienda para la siguiente version.
